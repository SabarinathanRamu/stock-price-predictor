Stock Price Predictor

A Machine Learning project that predicts future stock prices using historical stock market data.

Overview

This project uses Linear Regression to predict future stock prices based on historical closing prices downloaded from Yahoo Finance.

Features

- Historical stock data collection
- Data preprocessing
- Machine Learning prediction model
- Stock price forecasting
- Visualization of actual vs predicted values

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- yFinance

Installation

Clone the repository:

git clone https://github.com/SabarinathanRamu/stock-price-predictor.git

Install dependencies:

pip install -r requirements.txt

Run the project:

python app.py

Project Workflow

1. Download stock data.
2. Prepare training and testing datasets.
3. Train a Linear Regression model.
4. Predict future stock prices.
5. Evaluate model accuracy.
6. Visualize results.
